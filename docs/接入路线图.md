## 2. 真数口径（避免「看着跌其实涨」的坑）

所有 MTD 环比**对齐「7 月同期」而非「整月日均」**：

- 8 月 MTD（8/1–8/13）对比 **7/1–7/13**（同 13 天），不是对比 7 月全月除以天数。
- 原错误口径（MTD 对比整月日均）会得出「下滑」，因为月初往往低于月末；正确同期对比显示 8 月开局**实际向好**：营收 +21.8%、毛利 +27.1%、台次 +15.2%。
- 三维度真数（业务类别 / 服务顾问 / 车系）对同一窗口求和必须一致（当前偏差 0.000%），否则视为数据不自洽、拒绝写入。

## 3. 刷新架构（接通 ABS 后的日常运作）

```
WorkBuddy（hdhr-abs-connector 跑 QUERY_SQL.md 的查询）
        │  遵守护栏：只读 / NOLOCK / ≤92天 / TOP 5000 / 30s 超时 / 避开 08:30–18:30
        ▼
snapshot.json   ← 完整 cockpit 对象（含 meta/overview/sections/kpis/alerts）
        │
        ▼
node scripts/refresh_cockpit.js snapshot.json
        │  ① 结构校验  ② 重算 windowTotal 防截断  ③ 三维度真数对齐(≤0.5%)  ④ 写 data/data.js
        ▼
data/data.js  →  浏览器打开 index.html 即最新真数看板
```

- **落盘即真相**：`data/data.js` 是静态快照，离线可用、可审计、可回滚（git 历史即版本）。
- **自检闸门**：每次刷新后跑 `node docs/selftest.js`，26 个模块全部渲染无 `undefined/NaN`，且三维度真数对齐才允许发布。
- **定时化**：可挂 WorkBuddy 自动化，营业低谷（21:00 后）每日刷新售后真数；全量保客/流失名单按 ≤92 天窗口分段扫描后合并。

## 4. 数据源接入优先级

按「投入产出比 + 审批阻力」排序：

### 第一优先：ABS 工单状态视图（解锁 2 个模块，且不含 PII）
- 点亮：**保险车辆维修进度**（`service.insurance`）、**在修车风险管理**（`fin.risk`）。
- 只要字段：`工单号 / VIN / 进厂日期 / 当前节点 / 完工时间 / 交车时间 / 定损金额 / 预估维修款 / 已收金额`。**无客户姓名电话**，审批阻力最小。
- 模板见 `QUERY_SQL.md` §A「工单状态视图」。

### 第二优先：V_UC_NewCar 整车销售视图（解锁 2~3 个模块）
- 点亮：**销售订单管理**（`sales.order`）、**留存订单进度管理**（`fin.order`）；并让**客户总数管理**（`cs.total`）基盘从「有售后记录客户」扩展为「全量客户」（去重合并）。
- 必含字段：`订单状态 / 交车日期 / 定金金额 / 回款状态`，否则进度看板只能看开单不能看闭环。
- PII：客户ID 入只读视图前须由 ABS 侧脱敏。

### 第三优先：企微智能表格台账（零成本，今日可启动）
企业微信**已连通**，无需审批。用智能表格承接无系统源的台账，工作台每日拉取汇总：
- 展厅接待登记表 → 销售接待管理
- 战败原因登记表 → 销售战败管理
- 在修车进度看板 → 补齐在修车风险
- 人员主台账 / 固定资产台账 / 招聘需求台账 → 行政 3 模块
- 资金周报表（汇总口径）→ 店面资金管理

### 第四优先：CRM / 微盛 SCRM / 二手车视图
- CRM（销售易等）：线索、接待、战败、订单全链路。
- 微盛企微管家：全员营销素材分发、转发追踪、绩效简报（weisheng-distributor 已开发）。
- V_UC_Stock / V_UC_Sale / V_UC_Purchase：二手车库存、成交、收购台账（WF-01 区域对标已上线）。

## 6. 红线与护栏

1. **只读**：连接器只执行 SELECT，绝不写操作。
2. **NOLOCK**：所有表/视图加 `WITH (NOLOCK)`，避免锁表影响营业。
3. **跨度 ≤ 92 天**：单次查询必须带日期 BETWEEN；全量历史分段扫描，段间合并。
4. **限行**：默认 TOP 5000 或分页，单次不超 5000 行。
5. **超时**：单次 30s 超时保护，超时缩小跨度重试。
6. **时段**：全量回测/月报排 07:00 前或 21:00 后，避开 08:30–18:30 营业高峰。
7. **PII**：客户姓名/手机号/VIN 等经 `hdhr-pii-guard` 脱敏后方可流转；D15 合规基线达成前，含 PII 名单仅内部使用，禁止自动对客发送。
8. **不填假数**：任何未授权模块绝不编造数值，只展示接入路径。

## 7. 回滚与故障

- 刷新失败（三维度偏差 ≥0.5% 或结构缺失）：脚本拒绝写入并报警，旧 data.js 保持不变。
- 真数异常需回退：从 git 历史 checkout 上一版 data.js 即可，工作台立即恢复。
- 视图临时不可用：将对应模块 status 改回 `pending_auth`，页面自动降级为「待接入」展示，不出现脏数。
